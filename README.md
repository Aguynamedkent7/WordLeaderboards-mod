🏆 WordLeaderboards

WordLeaderboards is a simple Minecraft mod that tracks specific words players use and displays leaderboards or stats for them.
You can easily add, remove, and view tracked words — and see who’s said them the most!

📖 Features

📋 Track any word players say in chat

🧮 View word usage stats and leaderboards

🗑️ Add or remove tracked words at any time

👀 Everyone can use the commands — no admin required

⚙️ Commands
Command	Description	Example
/addword <word>	Adds a word to the tracked list.	/addword hello
/removeword <word>	Removes a word from the tracked list.	/removeword hello
/wordstats <word>	Shows detailed stats for a specific tracked word.	/wordstats hello
/trackedwords	Displays all currently tracked words.	/trackedwords
/wordprogress <word>	Shows progress or leaderboard for a specific word.	/wordprogress hello

💡 All commands can be used by any player (no permission level required).

📊 How It Works

Add words using /addword <word>.

The mod automatically counts how often players say tracked words in chat.

Use /wordstats or /wordprogress to see who’s leading the count.

Remove words anytime with /removeword.

🧱 Installation

Download the mod .jar file.

Place it in your Minecraft mods folder.

Launch the game with Forge or Fabric (depending on your build).

Enjoy tracking your server’s favorite words!
